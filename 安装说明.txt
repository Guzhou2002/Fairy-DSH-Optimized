================================================================
  Fairy-DSH 安装说明（照着做就行，不需要懂技术）
================================================================

  这份说明对应压缩包：
      Fairy-DSH-v0.2.3-一键部署版-含依赖.zip

  （如果你下的是"一键安装版"，本说明同样适用，只是第一次安装
    时会联网多花一两分钟，其余步骤一模一样。）


================================================================
  这个东西是干什么的
================================================================

  它是 DSH（DeepSeek Harness）的界面外观插件，装上之后：

    * 界面换成 HDD 深色风格（带角色立绘、动画、自定义滚动条）
    * 可选：让 DSH 把回复朗读出来（需要额外装 GPT-SoVITS，见第九节）

  插件默认是关闭的，装完不会自己改变你的界面，要你在设置里手动打开。


================================================================
  第 1 步：先确认你有 DSH（大约 10 秒）
================================================================

  能做到下面这件事，就说明你有：

      你能启动 DSH，并且用浏览器看到聊天界面

  ※ 如果你连 DSH 都还没装，请先装 DSH，插件装了也没用。


================================================================
  第 2 步：解压到 C 盘根目录（大约 1 分钟）
================================================================

  1) 找到你下载的 zip 文件，右键它
  2) 选「解压到当前文件夹」或「解压到 Fairy-DSH-...」
     （360压缩 / 7-Zip / Bandizip / WinRAR 都可以）
  3) 解压后会得到一个叫 Fairy-DSH 的文件夹
  4) 把这个 Fairy-DSH 文件夹整个移动到 C 盘根目录

  移动完成后，你电脑上应该有这个路径：

      C:\Fairy-DSH

  里面能看到这些文件（不用全认识，能看到就行）：

      install.cmd      安装用（双击它）
      uninstall.cmd    卸载用
      verify.cmd       自检用
      README.md        详细文档（不想看可以不管）
      安装说明.txt     就是本文件
      fairy-visual     主题插件
      fairy-voice      朗读插件

  ※ 为什么让你放到 C:\Fairy-DSH？
    因为这样下面命令里的路径最短、最不容易写错。
    如果你想放到别的地方也行，只是命令里的路径要跟着改。


================================================================
  第 3 步：安装（二选一，推荐 A）
================================================================

  ----------------------------------------------------------
  方式 A：双击安装（最省事）
  ----------------------------------------------------------

  1) 打开 C:\Fairy-DSH 文件夹
  2) 双击 install.cmd
  3) 会弹出一个黑窗口，让你按数字键选择装什么：

         1) 只装核心 UI            （只要主题外观，选这个）
         2) UI + 语音朗读          （主题 + 朗读，推荐）
         3) UI + 语音 + 余额挂件
         4) 全部 5 个插件
         5) 自定义
         0) 退出

     建议：想要朗读就按 2，只想要外观就按 1
  4) 按完数字后，它会提示「按任意键开始安装」——随便按一下
  5) 等它跑完，最后会显示「[完成] 安装成功」
  6) 按任意键关闭窗口

  ----------------------------------------------------------
  方式 B：手动敲两条命令（方式 A 失败时用）
  ----------------------------------------------------------

  1) 在 C:\Fairy-DSH 文件夹的空白处，按住 Shift 点右键
     → 选「在此处打开 PowerShell 窗口」或「在终端中打开」

     （如果找不到这一项：按 Win+R，输入 powershell 回车，
       然后输入  cd C:\Fairy-DSH  再回车）

  2) 复制下面这一行，粘贴进去，回车：

     dsh plugin --profile web add link:C:/Fairy-DSH/fairy-visual/dsh-fairy-visual

  3) 看到出现类似这样的一行，就表示成功：

     + dsh-fairy-visual 0.1.0 <- ...Fairy-DSH\fairy-visual\dsh-fairy-visual

  4) 想要朗读功能，再复制这一行，粘贴，回车：

     dsh plugin --profile web add link:C:/Fairy-DSH/fairy-voice/dsh-fairy-voice

  5) 两条都跑完就可以了

  ※ 提醒：路径一定用「正斜杠 / 」，不要用反斜杠 \
  ※ 嫌麻烦就直接复制粘贴，不要手打


================================================================
  第 4 步：重启 DSH（必须做，否则看不见效果）
================================================================

  1) 完全关闭正在运行的 DSH
     （在右下角托盘图标上右键 → 退出；或者关掉那个命令行窗口）
  2) 重新启动 DSH
  3) 等界面出来


================================================================
  第 5 步：强制刷新浏览器（必须做）
================================================================

  在 DSH 的浏览器页面上按：

      Ctrl + F5      （同时按住 Ctrl 和 F5）

  ※ 普通 F5 有时不够，一定要 Ctrl+F5


================================================================
  第 6 步：在设置里打开它（必须做）
================================================================

  1) 点界面里的「设置」
  2) 左侧找到「Fairy」这一项，点进去
  3) 找到「启用」开关，打开它

  做完这一步，界面才会变成 HDD 风格。

  ※ 插件默认是关的。装完不打开 = 什么都不会变，这是正常的。


================================================================
  第 7 步：确认装好了
================================================================

  打开设置 → Fairy，你应该能看到这些内容：

      * 视觉相关的一堆开关（主题、立绘大小、动画速度…）
      * 一个叫「朗读服务」的区域

  如果能看到，说明安装成功。


================================================================
  第八步：Fairy 人设（可选，不影响主题和朗读）
================================================================

  装好之后，DSH 里会多出一个叫 Fairy 的「人设预设」——它让回复用
  《绝区零》Fairy 的语气说话（正式、克制、带系统播报感的冷幽默）。

  怎么开启（两步，不用你自己去找设置项）：

    1) 打开 设置 -> Fairy
    2) 勾上「第 1 步」的开关（把预设装进 DSH）
       再点「第 2 步」旁边的按钮：一键设为默认预设

  做完这两下就好了 —— 以后每开一个新会话，都会自动带上 Fairy 人设。

  ★ 如果你更喜欢自己选，也可以手动来：
      新开一个会话，空白页上有一个「Agent 预设」选择器
      （或者 设置 -> Agent 预设），在里面选中 Fairy 即可。

  ★ 注意：只对「新建的会话」生效
    你当前正在聊的这个会话不会变。想看到效果，请新建一个会话再聊。

  首次打开设置时，你会看到一个红色的提示框提醒你还没做这两步；
  点「我知道了，不再提示」就不再打扰你（做完第 1 步它自然就消失了）。

  不想用了：
    回到 设置 -> Fairy，把「Fairy 人设预设」开关关掉；
    如果点过「一键设为默认预设」，记得再点一次「取消默认」，
    它会把默认预设还原成你原来的那个。
    已经用上它的会话不受影响，只是以后不会再出现在预设列表里。


================================================================
  第九步：朗读功能（可选，不想要可以跳过）
================================================================

  朗读需要你本机另外跑一个叫 GPT-SoVITS 的语音服务，
  它不在这个压缩包里，需要你自己另外部署。

  9.1 先点一次「开始自检」（v0.2.3 起）

      设置 → Fairy → 「朗读功能自检」→ 点「开始自检（含试合成）」。

      等几秒钟，下面会列出 7 项检查，每项都是：

          ✅ 或 ⚠️ 或 ❌   +   一句话说明   +   「怎么修」

      红色（❌）的那一项，就是你现在缺的东西。
      按上面写的「怎么修」做，再点「重新自检」就行。

  9.2 自检看到红色时，通常就是这两种

      ❌ 本地朗读服务（GPT-SoVITS）
         → 你还没启动 GPT-SoVITS。这不是插件的问题。
         → 如果你把它跑在别的端口、或者另一台电脑上，
           把地址填到「SoVITS 地址」那一栏，点「保存设置」即可，
           不用重启 DSH。
           （跨电脑时：对方要监听 0.0.0.0，并在防火墙放行端口。）

      ❌ 参考音频（决定音色）
         → 缺一段 3～10 秒的干净人声（.wav）。
         → 默认位置：C:\Users\你的用户名\.dsh\fairy-voice\runtime\reference\fairy_ref.wav
         → 音频放在别处也行，把完整路径填到「参考音频路径」，点「保存设置」。

  9.3 自检里那几项的含义

      * 朗读控件是否挂上 —— 插件有没有成功装进页面
      * 消息识别 —— 插件能不能读到"要朗读的那条回复"
      * 浏览器音频播放能力 —— 你的浏览器能不能出声

  没有 GPT-SoVITS 的时候：

      * 每条回复上的「朗读」按钮是灰色的，点了没声音
      * 自检面板顶部是一条红色横幅，写明还差哪几项

  这不是故障，是正常的。等你把 GPT-SoVITS 跑起来
  （默认端口 9880），点一下「重新自检」，红色就会变绿。

  9.4 自检还是看不出问题？

      点面板里的「复制诊断信息」，然后把剪贴板内容直接粘贴到群里
      （交流群 1124349108）。这份信息里只有检查结果和技术细节，
      **不包含你的聊天内容**。


================================================================
  常见问题
================================================================

  Q1. 双击 install.cmd，窗口一闪就没了？
      → 改用第 3 步的「方式 B：手动敲两条命令」。

  Q2. 提示「'dsh' 不是内部或外部命令」？
      → 说明你没装 DSH 的命令行工具，或者装完没重开终端。
        先确认 DSH 本身能用；装好 DSH 后重开一个 PowerShell 再试。

  Q3. 提示「Cannot find package '...'」之类的英文错误？
      → 你用的多半是「一键安装版」而当时没联网（或缺 pnpm）。
        换成「一键部署版-含依赖」那个包重做一遍即可。

  Q4. 装完了，界面没变化？
      → 按顺序检查三件事：
        ① 重启过 DSH 了吗
        ② 在浏览器里按过 Ctrl+F5 了吗
        ③ 设置 → Fairy → 「启用」打开了吗
        三条都做到，界面一定会变。

  Q5. 设置里找不到「Fairy」这一项？
      → 说明插件没加载成功。回到第 3 步方式 B 重做一次，
        注意命令里的路径要和你的实际位置一致。

  Q6. 杀毒软件报毒 / 拦截？
      → 误报。脚本只是往 DSH 的配置里写插件路径。选择「允许」即可。

  Q7. 我不想要了，怎么恢复原样？
      → 两种办法，任选：
        ① 设置 → Fairy → 把「启用」关掉（界面立刻恢复）
        ② 双击 uninstall.cmd → 按 1 → 重启 DSH（彻底卸载）

  Q8. 会不会影响我原来装的其他插件？
      → 不会。安装只往 DSH 里加两条插件记录，不动其它插件。
        而且卸载时会精确移除自己加的那两条。

  Q9. 安装脚本会不会乱改我的系统？
      → 不会。它只做四件事：备份你的 DSH 配置、往配置里加插件路径、
        把朗读面板并进设置栏、检查配置能否正常加载。
        改动前会自动备份，失败会自动还原。


================================================================
  卸载方法
================================================================

  1) 双击 C:\Fairy-DSH\uninstall.cmd
  2) 按 1（只卸载）或 2（卸载并还原安装前的配置备份）
  3) 重启 DSH
  4) 浏览器 Ctrl+F5


================================================================
  进阶：校验文件完整性（可选，不看也行）
================================================================

  担心下载过程中文件损坏，可以校验哈希值：

  1) 在 C:\Fairy-DSH 所在目录按住 Shift 右键 → 打开 PowerShell
  2) 输入下面这行回车（把文件名换成你实际的）：

     certutil -hashfile "Fairy-DSH-v0.2.3-一键部署版-含依赖.zip" SHA256

  3) 输出的哈希值应当和压缩包旁边 .sha256 文件里的一致
