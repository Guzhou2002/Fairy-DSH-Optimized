## 4. 这一轮新学到的（重要，别再踩）

### 4.1 🔴 用户数据绝不能放进插件目录

起因：看到参考音频默认在 `~/.dsh/fairy-voice/reference/`，而插件装在
`~/.dsh/plugins/Fairy-DSH/fairy-voice/dsh-fairy-voice/`，**第一反应是"路径写错了"** ——
于是把默认位置往顶层挪了一次，后来发现 `~/.dsh/fairy-voice/` **本来就存在**（是插件的数据目录），又挪回来。

**真相**：两个路径**故意不同、也必须不同**。`dsh plugin add <tgz>` 会把包解进
**profile 下的 `node_modules`** —— 那是 **pnpm 随时会清掉/重建/按版本重装**的目录。
把音色、API Key 放进去 = 放在定时炸弹上，升一次版本就没了。

**规矩**：用户数据一律 `~/.dsh/fairy-voice/`。判据一句话：
**任何会被 `pnpm install` / 插件重装影响到的目录，都不许放用户数据。**
（已写进 `AGENTS.md` §5.4.1、`交接摘要.md` §9 坑 16、README「你的东西放在哪」）

### 4.2 MOSS 相关的坑（4 个，实测）

| 坑 | 真相 |
| --- | --- |
| 官方 README 说"ONNX 版推理期不要 PyTorch" | **只对命令行成立**。`onnx_tts_runtime.py` 顶层硬 `import torch`；HTTP 服务还额外要 `transformers` |
| `huggingface_hub` 装成最新的 1.x | **跑不了**：它传的 `local_dir_use_symlinks` 在 1.0 已被移除。**必须 `<1`** |
| 用 `hf-mirror.com` 加速下载 | 证书**可能过期**。走**官方 + 梯子**（`HTTP(S)_PROXY`）更稳 |
| 官方 `app_onnx.py` 在 Windows 上起不来 | 它预热时**强制**加载 WeTextProcessing，而 **`pynini` 在 PyPI 上没有任何 Windows 轮子**（实测 0 个 `win` 文件）。所以本仓库自带 `server.py` 绕开它 |

### 4.3 两个工具层面的教训

- **`$ErrorActionPreference='Stop'` + 原生命令**：git/uv/python 往 stderr 写进度是正常的，
  但在 Stop 模式下会被当成**终止错误**、脚本当场退出（`install-moss.ps1` 第一版就死在这）。
  改用 `Continue` + 每步显式 `$LASTEXITCODE` 判断。
- **`edit` 工具改嵌套 JSX 时，`old_string` 要卡在成对的边界上**：
  这次我删多了，把「保存设置」按钮那段的开头一起替换掉，导致结构断裂 ——
  靠 **`node --check` 立刻抓到**。改完必跑。

## 5. 常用命令

```powershell
cd C:\Users\1\.dsh\plugins\Fairy-DSH

# 改了 lib\settings-merge.ps1 之后必做（两个 client.js 都是生成物）
. .\lib\settings-merge.ps1
Set-SettingsMerge -Root (Get-Location) -Mode merged -Snapshot -Force
node --check .\fairy-visual\dsh-fairy-visual\lib\client.js
node --check .\fairy-voice\dsh-fairy-voice\lib\client.js

# 改了 .ps1 之后（edit 工具会丢 BOM）
$p='lib\settings-merge.ps1'
$t=[IO.File]::ReadAllText($p,[Text.UTF8Encoding]::new($false))
[IO.File]::WriteAllText($p,$t,(New-Object Text.UTF8Encoding($true)))
$e=$null;[void][System.Management.Automation.Language.Parser]::ParseFile((Resolve-Path $p).Path,[ref]$null,[ref]$e);$e.Count

# 跑测试（⚠️ 只跑新加的那个快的；全套含 performance 会跑很久）
cd fairy-voice\dsh-fairy-voice
node --test test\moss-tts.test.js

# 打包 + 取 SHA
cd ..\..\ ; .\pack.ps1
Get-Content .\release\SHA256SUMS.txt

# MOSS 服务
& E:\MOSS-TTS-nano\start-moss.cmd                       # 启动（双击也行）
& E:\MOSS-TTS-nano\venv\Scripts\python.exe E:\MOSS-TTS-nano\verify.py   # 验证
Get-NetTCPConnection -LocalPort 18083 -State Listen     # 看谁占着

# 推送（代理不通时直连反而能成功）
git push origin main
```
