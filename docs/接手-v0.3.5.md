## 3. 这一轮新学到的（重要，别再踩）

### 3.1 🔴 `lib\settings-merge.ps1` 是 **LF 换行**，不是 CRLF

多行锚点用 `\r\n` 拼接会**一处都匹配不上**（单行锚点不受影响，所以现象很迷惑：一行能中、多行全 0）。

**正确写法**：

```powershell
$nl = if ($t.Contains("`r`n")) { "`r`n" } else { "`n" }
$old = (@('第一行', '第二行') -join $nl)
```

### 3.2 🔴 批量文本替换**必须先断言匹配数**，再写盘

这一轮做了 6 次批量替换，其中**两次**因为换行符/字符差异**命中数不为 1**。
因为写了「匹配数 ≠ 1 就 `throw`，且 throw 发生在写盘之前」，**文件一个字都没动**，改一行重跑即可。

```powershell
$c = ([regex]::Matches($t, [regex]::Escape($old))).Count
if ($c -ne 1) { throw '锚点匹配数不为 1，已中止，文件未改动' }
# ... 全部 pair 校验通过之后，才统一 Replace + WriteAllText
```

> 另：`settings-merge.ps1` 改完**必须补回 BOM**（`New-Object Text.UTF8Encoding($true)`）+ `Parser::ParseFile` 校验。

### 3.3 🟡 PowerShell 把命令行输出当成**行数组**

`$body = & gh release view ... --jq .body` 之后，`$body.Length` 是**行数**，不是字符数 ——
我因此误报过一次"Release 正文只有 105 字符"。**要 `$body = (...) -join "`n"` 之后再量。**

### 3.4 🟡 删 DOM 元素前，先查**谁在读它**

删「结构摘要」文本框时差点把上一轮的功能弄断 —— 因为 `copyDiagnostics` 当时是**从那个框里读现值**的。
现在的做法：删框 + 把 `const shapeText = (() => {...})()` 改成 `const readShapeText = () => {...}`，
复制时现算。**因为是函数，即使 `useCallback` 闭包是旧的，读到的也是 `window.__FAIRY_VOICE_DIAG__` 的当下值。**

> 排查手法：`Select-String` 搜符号名，确认**源码与生成物里都不再有旧引用**（这次搜出 1 处残留，是**注释**——安全，但已过时，顺手改准了）。

### 3.5 🟢 怎么**不重启**就验证「检查更新」的红字

写一份假缓存，然后**切走再切回设置页**（面板是挂载时查一次，F5 也行）：

```powershell
$p = "$env:USERPROFILE\.dsh\fairy-voice\update-check.json"
$now = [DateTimeOffset]::UtcNow.ToUnixTimeMilliseconds()
[IO.File]::WriteAllText($p, '{"tag":"v114.5.14","checkedAt":' + $now + '}', (New-Object Text.UTF8Encoding($false)))
# 看完删掉即恢复真实状态：Remove-Item $p -Force
```

⚠️ **必须用 `Utf8Encoding($false)`（无 BOM）**：带 BOM 会让 `JSON.parse` 失败 → 缓存被当成"没有"。
⚠️ **重启 DSH 会让宿主在 5 秒后覆盖掉这份假缓存**，所以试的时候别重启。

**判断"正在跑的实例是不是最新代码"**（不用 token 也能查）：

```powershell
$conn = Get-NetTCPConnection -LocalPort 3080 -State Listen | Select-Object -First 1
(Get-Process -Id $conn.OwningProcess).StartTime          # 进程启动时间
(Get-Item .\fairy-visual\dsh-fairy-visual\lib\client.js).LastWriteTime   # 代码时间
# 进程时间 > 代码时间 = 已加载最新；否则要重启
```

### 3.6 🟢 `startup 那条规则`别再犯：面板改动**隔离验证证明不了渲染**

`verify-isolated.ps1` 只能证明"插件能加载、DOM 探针不报错"，**证明不了面板长得对**（它甚至不一定打开设置页）。
**面板类改动必须重启后肉眼看**（本轮 6 项全部按此验收）。
