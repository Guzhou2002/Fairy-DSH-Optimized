## 1. 怎么自己重新生成这份清单

```powershell
cd C:\Users\1\.dsh\plugins\Fairy-DSH

git fetch upstream                                   # 拉上游最新（本机可能卡，见 docs\交接摘要.md 注意事项 8）
git diff --name-status upstream/main...main          # 只看分类：A增 M改 R改名 D删
git diff --stat upstream/main...main                 # 带增删行数
git diff upstream/main...main -- <某个文件路径>       # 看某个文件到底改了什么
```

> 三个点 `...` 的意思是"**只算我这边的改动**"，上游自己新增的文件不会混进来。
